# 20-coding68
ใช้เรียน
ฝึกในวิชาเขียนโปรเเกรม
ใช้ต่อยอดในอนาคตได้
ขั้นตอนโปรเเกรมเเบ่งเวลาการออกกำลังกายในเเต่ละวัน

ระบุปัญหา ออกกำลังกายไม่เห็นผล
ตั้งเป้าหมายของโปรแกรม ออกกำลังกายให้เเข็งเเรงขึ้น Input = เวลาที่มีสำหรับออกกำลังกายทั้งหมดต่อสัปดาห์
Process = รับค่าเวลาการออกกำลังกายทั้งหมด Output = แสดงเวลาออกกำลังกายในแต่ละวัน
ผลการวิเคราะห์ตนเองกับโจทย์

ยากเเต่ทำได้ครับ
เกมชอบผังงานมากกว่าเพราะทำง่ายกว่า
ยากที่สุด คือ ขั้นตอน Process ถ้าออกกำลังกายน้อยก็ไม่เห็นผล
ความสามารถของโปรเเกรม ทำให้ออกกำลังกายเเล้วเห็นผลเเละใช้เวลาอย่างคุ้มค่า
เครื่องมือที่ใช้ได้เเก่ Python
ชื่อผู้พัฒนา นายพัชรพล สองสี
ครูผู้สอนครูนฤล สุนทอง
